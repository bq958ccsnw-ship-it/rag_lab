# Общие правила этапа

Срок этапа — 7–10 календарных дней. Все работают на одном корпусе и начинают с одного baseline.

Перед изменениями запустите:

```powershell
python run.py evaluate --output results\baseline.json
python -m unittest discover -s tests -v
```

До первого эксперимента запишите гипотезу и ожидаемый эффект. В одном эксперименте меняйте один фактор. Сохраняйте точную команду, конфигурацию, метрики и краткий вывод. Не выбирайте параметры по закрытому test.

Минимальный отчёт должен ответить на вопросы:

1. Что изменили и почему?
2. Какая метрика должна была измениться?
3. Что получилось на dev?
4. Какие типы ошибок остались?
5. Подтвердилась ли гипотеза?
6. Какую конфигурацию вы фиксируете перед test?

Запрещено добавлять LangChain или LlamaIndex: цель этапа — увидеть chunking, векторы, cosine и top-k напрямую. Внешние API и RNGPT не используются.
