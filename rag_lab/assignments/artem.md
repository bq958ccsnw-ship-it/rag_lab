# Артём — evaluation harness

Сделай воспроизводимую оценку retrieval. Baseline уже умеет считать метрики; твоя задача — превратить его в удобный экспериментальный стенд, а не переписать всё с нуля.

Обязательная часть:

- сравнить k = 1, 3, 5 и 10;
- добавить сводку по категориям и сложности вопросов;
- выбрать один фактор: chunk size, overlap или backend;
- провести контролируемое сравнение минимум трёх значений фактора;
- построить таблицу результатов и разобрать пять ошибок;
- зафиксировать лучшую конфигурацию до test.

Сдать код, команды запуска, таблицу, отчёт и один вывод, который подтверждается данными. Не использовать test для выбора конфигурации.
