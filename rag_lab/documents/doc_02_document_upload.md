# Загрузка документов

## Поддерживаемые файлы

VirtHelp принимает файлы PDF, DOCX, PPTX, XLSX, TXT, Markdown и CSV. Максимальный размер одного файла — 50 МиБ. За один пакет можно передать не более десяти файлов. Архивы ZIP и исполняемые файлы не принимаются.

Перед загрузкой пользователь выбирает базу знаний и подтверждает, что документ не содержит секретов, которые запрещено размещать в этой среде. Имя файла сохраняется как метаданные, но не используется как единственный идентификатор документа.

## Статусы обработки

После загрузки версия последовательно получает статусы `ACCEPTED`, `PARSING`, `INDEXING` и `READY_FOR_VERIFICATION`. Ошибка разбора переводит версию в `PARSING_FAILED`, ошибка построения индекса — в `INDEXING_FAILED`. Повторная загрузка того же файла создаёт новую версию, а не перезаписывает старую.

Пользователь может закрыть страницу после появления статуса `ACCEPTED`: обработку выполняют фоновые работники. Готовность к публикации означает, что исходный текст извлечён и индекс построен, но документ ещё не виден обычным пользователям.
