# Подключение моделей RNGPT

Для семантического поиска применяется `Qwen3-Embedding-0.6B`, для реранжирования — `bge-reranker-v2-m3`, для учебной генерации по умолчанию — `Qwen3.5-9B`. Список доступных моделей может меняться, поэтому приложение проверяет каталог моделей, а эксперимент фиксирует точный идентификатор.

Сервис RNGPT доступен только из корпоративной сети или через VPN. Нужен доверенный корпоративный сертификат. Отключать проверку TLS для обхода ошибки сертификата запрещено.

Каждый участник использует собственный персональный или специально выданный сервисный токен. Токен хранится только в локальном `.env`, не публикуется в Git, отчёте или сообщениях. Внешний запрос содержит технический токен и атрибуцию пользователя: логин и корпоративную почту.

Тайм-аут запроса эмбеддингов в учебной песочнице равен 30 секундам. Недоступность модели должна завершать эксперимент явной ошибкой, а не незаметным переходом на другой алгоритм. Сравнивать результаты разных embedding-моделей можно только при зафиксированных остальных параметрах.
