# Мониторинг локального VirtHelp

Каждый прикладной сервис предоставляет `/health/live`, `/health/ready` и `/metrics`. Liveness показывает, что процесс работает. Readiness проверяет необходимые зависимости и означает, что сервис готов принимать рабочий трафик. Успешный liveness при ошибочном readiness не считается здоровым стендом.

Prometheus доступен локально на порту 9090 и собирает метрики девяти прикладных компонентов. Пользовательский интерфейс открыт на порту 8080, административный — на 8081, Keycloak — на 8082. Assistant API использует порт 8100, Admin API — 8101.

Для очередей используется RabbitMQ; его интерфейс управления доступен на порту 15672. Консоль объектного хранилища MinIO доступна на порту 9003. Эти интерфейсы предназначены для диагностики и не заменяют пользовательские приложения.

После полного запуска ожидаются 15 постоянно работающих контейнеров в состоянии `healthy`. Одноразовые контейнеры миграций и проверок могут завершаться с кодом 0 и не входят в число постоянно работающих. При сбое сначала проверяют readiness конкретного сервиса, затем его зависимости и ограниченный хвост журналов.
